- **内容**：在学习初期快速写下关键词，即使不准确或不完整，目的是将思维外化以可视化想法，自由猜测概念间关系，为大脑后续学习做好准备，避免因追求完美而导致的分析瘫痪。
- **说明**：这是纸上思考方法的第一步，重点在于克服完美主义倾向，通过"犯错"来启动学习过程。
