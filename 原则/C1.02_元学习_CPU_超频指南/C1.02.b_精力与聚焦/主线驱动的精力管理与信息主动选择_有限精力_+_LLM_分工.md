**精力有限 → 主动选择主线 → 信息源过滤 → 第一性原理+80/20 → LLM 只负责执行**

#q 目标是什么？ 有限精力需要基于主线主动选择筛选信息
找到定位和主线，找到适合自己的source，根据主线来关注相关的news，找到合适的content来快速理解事物。过滤掉流量内容，精力放在有确定性回报的内容。

#s  人承担战略思考LLM负责行动执行
> 人机协作边界： 不需要llm来筛选信息，我来思考，llm来行动。  [[清晰思考框架_本质拆解+二八抓手]]

目标：
过程：好的信息来源（订阅的视频、官方网站, NEWS新玩意, SOURCE完整版,CONTENT二次加工 ） → 总结要点列表 → 第一性原理和二八原则
工具： n8n 自动化监控更新和抓取信息 ， claude code skill处理。

疑问：我需要学习的知识，要学已经经典的还是最新的技术？这不是浪费精力，MVP实现功能就行，不用最新的技术，用最稳定的。 

---

**你来思考（战略决策 + 判断），LLM 来行动（执行 + 输出）。**

“都思考什么？”——核心是**所有需要主观价值判断、长期视野、个人语境匹配的环节**，这些是 LLM 无法替你决定的。以下是基于你笔记里已经提到的内容，整理出的**完整思考清单**（可以直接复制到笔记里继续完善）：

- **定位与主线**  
  - 我这一阶段（3-6个月/1-3年）最核心的1-2条主线是什么？（例如：AI 落地能力、个人品牌、特定行业深耕…）  
  - 我的独特优势/兴趣/资源匹配点在哪里？（第一性原理拆解：我真正想解决的问题是什么？）

- **信息源的筛选与维护**  
  - 哪些来源**真正适合我**（深度、更新频率、信号噪音比高）？列出 Top 5-8 个订阅源，并定期复盘。  
  - 过滤标准是什么？（必须有确定性回报 / 能直接服务主线 / 非纯流量 / 作者/机构可信度…）

- **关注与过滤规则**  
  - 每天/每周看到的新东西，**先问**：这和我的主线有直接关系吗？能产生确定性回报吗？  
  - 流量内容/热点/争议话题的触发条件是什么？（看到就跳过）

- **学习与知识选择的优先级**  
  - 需要学的知识：**经典稳定版** vs **最新技术**？  
  - 判断标准：MVP 是否能跑通？用最稳定方案先落地，最新技术只在验证后才考虑。  
  - 什么知识属于“高确定性回报”？（能立刻用到项目/输出/决策中）

- **第一性原理 + 二八原则的应用**  
  - 拿到信息后，我要思考：核心本质是什么？80% 结果来自哪 20% 的关键点？  
  - 哪些部分值得我亲自深挖，哪些可以直接丢给 LLM 总结/代码实现？

- **LLM 行动边界**  
  - 具体委托给 LLM 做什么？（例：把这 5 个来源的更新抓成要点列表、用 n8n 自动化监控、生成代码实现 MVP、整理成结构化笔记…）  
  - 每次委托前我必须给出的**明确指令**是什么？（避免 LLM 自己判断）
