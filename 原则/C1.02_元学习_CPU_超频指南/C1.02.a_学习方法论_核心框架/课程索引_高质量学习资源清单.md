## 使用建议

### 选课原则

1. **需求驱动**: 根据当前项目需求选课
2. **由浅入深**: 先基础课，再高级课
3. **实战导向**: 优先选有项目的课程
4. **质量>数量**: 完成1门好课胜过开始10门课

### 学习策略

```markdown
## 课程学习SOP
1. [ ] 快速浏览课程大纲（30分钟）
2. [ ] 1.5倍速看视频
3. [ ] 做笔记（用自己的话）
4. [ ] 完成所有作业/项目
5. [ ] 写学习总结
```

### 时间分配

- 每周学习时间: 5-10小时
- 每门课程周期: 4-8周
- 每年完成课程: 4-6门
