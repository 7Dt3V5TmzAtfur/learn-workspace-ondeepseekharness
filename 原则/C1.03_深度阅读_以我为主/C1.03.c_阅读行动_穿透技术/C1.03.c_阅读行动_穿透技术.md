# [[C1.03.c_阅读行动_穿透技术]]

> **逻辑脉络**：
> 好的阅读并非匀速运动，而是一场由 **[[C1.03.c.01_战略预读与价值质检]]** 发起的进攻。我们通过 **[[C1.03.c.02_物理加速与视幅节奏]]** 快速掠过信息平原，在发现高价值猎物后，切换至 **[[C1.03.c.03_深度穿透与逻辑剥离]]** 进行近战。最终通过 **[[C1.03.c.04_逻辑重构与原子输出]]** 将战利品转化为长久资产。整个过程由 **[[C1.03.c.05_阅读场域与状态驱动]]** 提供稳定的能量供给。

- **输入端 (Pre-reading)**：关注书籍筛选、元数据获取、大纲构建。
- **执行端 (Rhythm & Speed)**：关注视幅扩大、节奏控制、划线辅助。
- **深度端 (Processing)**：关注逻辑拆解、压力测试、批判思考。
- **输出端 (Internalization)**：关注 MOC 构建、卡片化、自我关联复述。
- **环境端 (Context)**：关注场域心理、启动策略、媒介选择。

## 1. 🔍 战略预读 (Pre-reading)
在深入细节前，必须完成“元数据攻击”。通过 [[书籍外显元数据快速质检]] 和 [[AI预构阅读框架]] 建立视觉索引，确保后续的阅读是带着问题进行的“有色阅读”。

## 2. ⚡ 物理配速 (Speed)
利用 [[16格三点速读法|16格笔记法]] 和 [[意群扫描与周边视野练习]] 打破声音依赖。重点在于 [[快慢快节奏阅读法]]：在非核心区加速，在锚点区停留。

## 3. 🧠 深度穿透 (Processing)
不盲从权威。利用 [[苏格拉底式批判阅读]] 和 [[概念观点压力测试]] 寻找逻辑漏洞。对于晦涩文本，采取 [[难点突破侧攻法]] 实现降维打击。

## 4. 📝 知识内化 (Internalization)
笔记不应是抄写，而是 [[破坏性书写交互笔记]]。通过 [[一分钟复述约束]] 检验理解深度，并将结果拆解为符合 LifeOS 规范的原子卡片。

## 5. 🔋 场域驱动 (Environment)
建立 [[感官锚定与巴甫洛夫式启动]]。在 [[碎片化时间阅读流]] 中维持语感，在深度场域中构建心流。理解 [[速读的整体认知优势]] 是消除“读太快会忘”心理障碍的关键。

let rows = [];

if (folderObj && folderObj.children) {
    // 遍历当前文件夹下的所有子项并按名称排序
    const children = folderObj.children.sort((a, b) => a.name.localeCompare(b.name));

    for (let child of children) {
        // 1. 判断是否为文件夹 (child.children)
        // 2. 判断文件夹名称是否在排除列表 (excludeList) 中
        if (child.children && !excludeList.includes(child.name)) {
            
            const subFolderName = child.name;
            const subFolderPath = child.path;
            
            // 构造预期的同名文件路径：子文件夹路径/子文件夹名.md
            const expectedFilePath = `${subFolderPath}/${subFolderName}.md`;
            
            // 尝试通过 Dataview 获取该文件的元数据
            const page = dv.page(expectedFilePath);
            
            let desc = "";
            let nameDisplay = subFolderName; // 默认只显示文字名称

            if (page) {
                // 情况 1: 同名文件存在
                desc = page.description ? page.description : "";
                
                // 将第一列设为可点击的链接
                nameDisplay = page.file.link;
            } else {
                // 情况 2: 同名文件不存在
                desc = ""; 
            }

            // 添加一行数据
            rows.push([nameDisplay, desc]);
        }
    }
