# SOP - 书籍阅读

决定阅读哪本书？ 对自己的提问，我的目的是什么？

[[拆书流程]]

[[论文式阅读方法]]、[[《高分读书法》]] - 核心：多次反复迭代

#### 1. 快速上手

引言和目录生成全书的逻辑框架，理解行文逻辑和结构，记录思维导图。
快速浏览引言和目录，提问自己想要解决哪些问题，记录下来 `-[]`。

#### 2. 阅读每一个章节

内容逻辑上理解：
```
总结逻辑，一条一句话

分类（希望得到整合和深化。需要把这些分散的策略串联成有机体系，同时保持原内容的精髓。）
```

总结一段话在开始：
```
浓缩成一段流畅的高度浓缩的一段话要点总结，便于背诵、快速掌握和记忆所有核心要义：

```
