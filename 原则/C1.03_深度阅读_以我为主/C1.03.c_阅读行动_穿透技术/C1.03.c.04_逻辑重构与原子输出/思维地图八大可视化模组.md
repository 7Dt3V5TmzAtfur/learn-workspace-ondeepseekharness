- **内容**：8 种基础图谱对应 8 种核心认知逻辑，用于精准解构书籍或构建写作框架：

	1.  **圆圈图 (Circle)**：定义语境/视角 → 观点性写作。
	2.  **气泡图 (Bubble)**：描述属性/角色 → 描述性写作。
	3.  **双气泡图 (Double Bubble)**：比较与对比 → 比较性写作。
	4.  **树状图 (Tree)**：分类/主次观点 → 说服性写作。
	5.  **括号图 (Brace)**：整体与部分拆解 → 技术性写作。
	6.  **流程图 (Flow)**：时间线/排序/情节 → 叙事性写作。
	7.  **复流程图 (Multi-Flow)**：因果关系/冲突解决 → 预测与因果分析。
	8.  **桥型图 (Bridge)**：类比推理/隐喻 → 类比性写作。
