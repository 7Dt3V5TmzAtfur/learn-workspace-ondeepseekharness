- **内容**：针对电子阅读的视觉干扰技术。设置快捷键（如 `F9`）执行"**选中实词 + 加粗**"宏命令。操作流：快速扫视 → 发现核心词（名词/动词） → 按 `F9` 加粗 → 利用字体突变强制视觉聚焦（停顿理解） → 迅速连接下一意群。
- **说明**：源自"电子书阅读方案"，将工具设置与行为模式结合。

**设置快捷键 (核心工具):**
    -   **目的:** 快速标记关键实词（名词、动词、形容词），强制视觉聚焦。
    -   **操作:** 在阅读软件（如Calibre, Adobe Acrobat Reader, 或支持宏的阅读器）中，将 `F9` 键设置为执行以下宏命令或组合操作：
        -   **选中当前词/词组：** 大部分阅读器支持双击选中单词，三击选中段落。确保 `F9` 能作用于当前选中的文本。
        -   **应用加粗格式：** `F9` 按下后，立即将选中文本加粗。
        -   **(可选) 短暂停顿：** 在宏命令中，加入一个非常短暂的停顿（例如0.3秒），模拟"慢下来理解"的节奏。*（这步实现可能依赖特定软件或脚本能力）*
    -   **替代方案 (如果无法设置宏):** 手动使用鼠标或触控板快速双击选中实词，然后按 `Ctrl+B` (Windows) / `Cmd+B` (Mac) 加粗。虽然不如一键 `F9` 流畅，但习惯后也能达到效果。
