- **内容**：对作者的核心观点、概念进行攻击性追问（破坏性测试）。寻找"反例"（什么情况下不成立）、界定"边界"（适用范围在哪里）、请求"溯源"（理论依据是什么）。通过寻找逻辑漏洞和既有经验的冲突，完成从接受者到对话者的身份转变。
- **说明**：[方法工具] 批判性思维的具体落地，避免盲从权威。
- **关联**：[属于] [[苏格拉底式批判阅读]]；[延伸] [[第一性原理]]
- **位置**：[向上追溯] [[C1.03.c_阅读行动_穿透技术]]；[向下拆解] [[逻辑谬误识别]]
%%
- **追问反例**："这个观点在什么情况下不成立？"
- **追问边界**："这个概念的应用边界在哪里？"
- **请求溯源**："这个说法的理论来源是什么？"
