8、先理解后评判：以开放心态接触新内容，在确保理解作者观点前**暂缓批判性评判**。通过搁置初始异议或偏见，能确保完整把握论证逻辑，从而提升记忆效果并形成公正批判。过早开始批判可能导致注意力集中在反驳或情绪反应上，反而忽略内容要点。

# 2. 品质：理解方式
## 2.1. 纵向深度
读、吸收
理解、归纳
记忆、总结、提升：思考如何在现实中运用改变自己的行为

## 2.2. 横向范围
纲领，摘要，总结
细枝末节
尽信书不如无：批判思考、提问回答

**内容**：书籍仅是作者思维的有限载体，且常含过时或错误信息。阅读应持批判态度，不迷信铅字，将其视为需要验证的“笔记”，而非绝对真理。
**说明**：核心观点。源自对“印成铅字即知识”的否定。
**关联**：支撑 [[林迪效应选书原则]] (选书策略)；对立 [[经典书籍的跨时空通用性]] (经典价值)。

千万不要误以为印成铅字的，都是宝贵的知识

书籍作为信息载体具有局限性，只能尽可能地表达作者的大部分思维内容，而书籍中的新信息往往会带来错误、不完整的观点，接收者需要谨慎对待。

把书籍当笔记看（批判思考），把笔记当书籍看（整理实践）；

建议你在未来的笔记中增加一个属性标签：`#Validated`（已验证）或 `#Theory`（理论阶段）。这能帮你区分哪些是书上说的，哪些是你实践过确认有效的。
