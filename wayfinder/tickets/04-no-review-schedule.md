# TICKET: 阶段走到 drilled 就结束了——存下来的数据永不召回

- **状态**: open
- **类型**: `task`（AFK — 补功能，不需决策）
- **阻塞**: 无
- **所属**: [MAP](../../map/MAP.md)

## Question

现在的阶段状态机是单向的：

```
ingested → planned → annotated → mapped → recalled → drilled → done
```

走到 `done` 就再也不动了。于是：

- `terms.jsonl`（术语追问记录）**永不复习**
- `qa.json`（读完自测）**永不复习**
- `annotations.json`（37 条标注）**永不复习**
- `drills.jsonl`（费曼复述）**永不复习**

数据都存在，但不会再被打开第二次。

## 为什么这是硬伤

原则原文 `交替练习与间隔效应.md`：

> 「最佳复习间隔通常约为目标记忆时长的 10%-20%」

即目标"记一年"→ 间隔约 1 个月；目标"记一周"→ 间隔约 1 天。文章给的实操节奏是 **1 天 / 3 天 / 1 周**。

`收藏不等于拥有_未读积压是自我否定.md` 批判的正是这件事：

> 「收藏不等于拥有」

我现在做的，就是让用户"收藏"了一堆标注和 QA，然后永远不提醒他回来看——**系统的行为恰好是原则批判的那种行为**。

## 数据结构上要加什么

`meta.json` 里现在有 `stage`、`progress`。需要加：

```json
{
  "drilledAt": "2026-10-24T04:30:00Z",
  "review": {
    "round": 0,
    "dueAt": "2026-10-25T04:30:00Z",
    "schedule": [1, 3, 7],
    "history": [{ "at": "...", "round": 0, "selfRating": "记得" }]
  }
}
```

规则：
- `drilled` 完成 → `dueAt = drilledAt + 1天`
- 用户完成一次复习 → `round += 1`，`dueAt = 上次 + schedule[round]`
- `round` 走完 3 轮 → 标记 `settled`，不再提醒
- 到期未复习 → `study_status` 的 `next` 指向 `review` 而不是 `done`

## 界面上怎么呈现（这是难点）

容易踩的坑：做成"通知轰炸"会让人反感。

原则原文 `触发式行动索引.md` 和 `五分钟行动具身启动法.md` 都强调**低门槛启动**：打扰要少，触发要准。

所以设计上：
- 不做系统通知，只在「学习工作台」顶部显示一行：「《XX》今天该复习了（第 1 轮，约 5 分钟）」
- 点进去直接进入复习模式：**只显示问题，不显示答案**，点"想起来了/忘了"自评
- 复习模式一次只过 5 条，不要求全部过完

## 需要确认的点

1. 「复习」是复用 `qa.json` 的问答，还是要把 `annotations.json` 的标注也做成"看着标签猜内容"？
2. 自评用二档（记得/忘了）还是三档（轻松/费力/忘了）？三档能算更准的下次间隔（类似 SM-2），但操作更重。
