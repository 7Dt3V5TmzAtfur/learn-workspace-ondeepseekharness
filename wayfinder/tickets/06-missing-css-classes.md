# TICKET: 7 个宿主 class 在客户端没有 CSS 规则

- **状态**: open
- **类型**: `task`（AFK — 补 CSS，无需决策）
- **阻塞**: 无
- **所属**: [MAP](../../map/MAP.md)

## Question

宿主渲染 HTML 时生成的 class，客户端 CSS 里没有对应规则。不是"样式不完美"，是**样式完全不存在**。

用 `tests/audit-styles.mjs` 程序化核对的结果：

```
宿主生成的 class：34 个
客户端有 CSS 规则：27 个
缺失：7 个
```

| 缺失 class | 出现在哪 | 用户看到什么 |
|---|---|---|
| `sc-tag-en` | `<span class="sc-tag-en">Definition</span>` | 英文副标签直接挤在中文后面：「#d 五类工具的审视特征Definition」 |
| `sc-seg-note` | 段落备注 `<div class="sc-seg-note">全章地基：两个审视特征</div>` | 37 条备注变成和正文一样的裸文本，分不清哪句是原文哪句是标注者的批注 |
| `sc-pf-sec` | 六段式的六个 section 容器 | 六段之间没有分隔，13KB 内容糊成一片 |
| `sc-pf-body` | 六段式的正文区 | 同上 |
| `sc-list` | 列表容器 | 列表失去缩进 |
| `sc-table` | 表格 | 表格失去样式（表头、边框、斑马纹） |
| `sc-kp-b` | 知识点条目的某个块 | 知识点区排版塌陷 |

## 为什么接口测试没发现

`audit-ui.mjs` 检查的是"渲染出来的内容对不对"（有没有 `<strong>`、有没有坐标）。HTML 结构完全合法，只是缺 CSS —— 所以 44 项审计全绿，用户打开却看到"标签粘连、备注没有区分、六段糊在一起"。

这是**测试盲区**：结构正确 ≠ 视觉正确。

## 三个维度的思考

**维度一：用户视角**
用户说"不美观"，他看到的不是"配色不好看"，而是：
- 中英文挤在一起（`sc-tag-en` 缺失）
- 备注和原文分不清（`sc-seg-note` 缺失）
- 六个部分之间没有视觉分隔（`sc-pf-sec` 缺失）
- 表格和有序列竖线糊成一段（`sc-table`/`sc-list` 缺失）

这些都是"缺少样式"，不是"审美不佳"。补齐就能解决大半。

**维度二：工程视角**
根因是**渲染契约没有单一来源**：宿主用字符串拼 HTML 写死了 class 名，客户端 CSS 靠手写记忆匹配。新增一个 class 时两边不会互相同步。

**真正该做的不是补 7 条 CSS，而是让这种失配不可能发生**：
- 方案 A：宿主和客户端共享一个 `RENDER_CONTRACT` 常量表（class 名集中定义）
- 方案 B：加 `audit-styles.mjs` 到测试流水线，任何新增未定义 class 直接失败（**已实现**）
- 方案 C：宿主不用 class，全部用内联 style（放弃，无法主题化）

选 B + A：B 立刻拦住回归，A 长期消除重复。

**维度三：可维护性**
`client.js` 现在 1250 行，CSS 是开头一大段模板字符串。补 7 条 CSS 会让它更长。
但这不该靠"重构整个 client.js"解决——那是无底洞。正确做法是只补缺的，并留审计脚本守住。

## 需要哪种视觉形态（要确认）

补 CSS 不是随便加几行 —— 每个 class 补成什么样决定了界面观感：

1. `sc-tag-en`：应该做成
   - (a) 右侧灰色小字，`font-size: 9px; opacity: .55; margin-left: 6px`
   - (b) 完全隐藏（只保留在 title 提示里）
   - (c) 做成中文后面的括号，如 `五类工具的审视特征（Definition）`

2. `sc-seg-note`：应该做成
   - (a) 左侧竖线 + 斜体灰字（引注样式）
   - (b) 淡黄底色块（便签样式）
   - (c) `border-top: 1px dashed` + 小字

3. `sc-pf-sec`：六个部分之间
   - (a) 卡片式（每段一个圆角白底卡片）
   - (b) 分隔线 + 序号标题
   - (c) 折叠面板（默认展开第 1 个）

这三项需要用户选。其余 4 个（`sc-pf-body` / `sc-list` / `sc-table` / `sc-kp-b`）是纯排版补全，按现有 `.sc-md` 风格补即可。
